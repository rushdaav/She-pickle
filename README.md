---

## 📖 Overview

**SHE PICKLE** is a modern, minimal, and visually memorable D2C e-commerce storefront designed for an authentic homemade pickle brand. Combining traditional South Indian culinary heritage with contemporary packaging aesthetics, the platform delivers an engaging shopping experience featuring realistic glass jars, smooth scroll animations, and instant checkout options.

### 🌟 Design Inspiration
- **CAKELAB**: Editorial typography hierarchy, clean spacing, and warm cream background palette.
- **DUNKLY**: Playful, hand-drawn vector illustrations (chillies, mangoes, lemons, prawns, dates, star anise, curry leaves, and ceramic bharanis).
- **TONIC DRINKS**: Bold hero typography, centered realistic product jar, infinite horizontal marquee, and scroll-driven storytelling.

## ✨ Key Features

1. **Section 01 – Hero Section**:
   - Oversized headline (*"THE TASTE THAT STAYS."*), centered commercial glass jar with hover lid twist-off & aroma effect, floating vector ingredients, and continuous marquee ticker.
2. **Section 02 – Sticky Scroll Jar Experience**:
   - Full-screen sticky presentation synchronizing product names, flavor notes, spice meters, and interactive weight selection (`250g`, `400g`, `800g`) with instant Add to Cart.
3. **Section 03 – Two Worlds of Flavour**:
   - Split-screen showcase comparing Vegetarian varieties (warm greens/mustards) and Non-Vegetarian varieties (deep chilli reds/earthy tones).
4. **Section 04 – Why SHE Pickle?**:
   - Four core pillars: *No Added Preservatives*, *No Added Colours*, *Bold Heirloom Flavours*, and *Slow-Cooked with Care*.
5. **Section 05 – Product Collection**:
   - Comprehensive grid with filter tabs (`All Pickles`, `Vegetarian`, `Non-Vegetarian`), weight switchers, and hover zoom interactions.
6. **E-Commerce & Checkout**:
   - Slide-out pantry drawer with real-time free shipping threshold tracker (free delivery over ₹699).
   - Coupon system: `WELCOME10` (10% off), `PICKLELOVE` (15% off), `FREESHIP` (Free shipping).
   - Dedicated Checkout with address validation, delivery options, and **Direct WhatsApp Ordering** (`https://wa.me/917034513689`).
   - Order confirmation with celebratory confetti and itemized invoice receipt.

## 🚀 Getting Started

### Prerequisites
- Node.js (v20+ recommended)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone <repository-url>
cd "She Pickle"

# Install dependencies
npm install
```

### Running Locally
```bash
# Start development server on localhost and local network IP
npm run dev -- --host 0.0.0.0 --port 3000
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

### Building for Production
```bash
npm run build
```
